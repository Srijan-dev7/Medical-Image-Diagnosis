# Medical Image Diagnosis System

A deep learning project for classifying medical images and detecting
common abnormalities using CNN-based models.

## About the Project

The goal of this project is to build a single application that can
identify the type of medical image provided by the user and then use
a specialized model to analyze it.

The project currently focuses on three types of medical images:

- Chest X-rays — Pneumonia detection
- Bone X-rays — Fracture detection
- Brain MRI — Tumor detection

The models will be trained using transfer learning and the final
system will be deployed as a web application using Streamlit.
